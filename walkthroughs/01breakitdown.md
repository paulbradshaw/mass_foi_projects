# 1: Break the project down into problems

The first thing to do with a mass FOI project is break down the multiple problems you will need to solve, and then put them into a logical order.

Here are typical inconsistencies that you will need to fix when dealing with multiple requests, and strategies for dealing with them:

1. Inconsistent level of detail. Strategy: prioritise (choose a level to focus on)
2. Inconsistent filetype. Strategy: extract data into one format (CSV)
  * Combine sheets from XLSX
  * Extract table from DOC
  * Extract table from PDF
3. Inconsistent data shape. Strategy: reshape data (wide to long, all fields)
4. Inconsistent categories/names. Strategy: clean data (standardise)
5. Inconsistent timescales. Strategy: report accurately with caveats (edit)
